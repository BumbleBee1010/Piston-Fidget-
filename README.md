# Piston Fidget
The Piston fidget I have created is a resin printed cylinder with a rotating base on some 6802 bearings. The piston 'cylinder' is a 12mm metal rod and it should slide into the cylinder and be able to float/spin using air pressure. It will feel like a high quality, premium fidget toy. Because it is 30mm in diameter and 110mm in height it is quite pocketable and about the size of a torch.

## Goal
My goal for this project was to make something fun and interesting with CAD, I also wanted to use resin because I have never used it before.

## Design
It can be resin printed, the base features wavy textured lines for a premium aesthetic and the top grip features concentric circles. You may notice, that the actual piston cylinder is plain, this is to keep a minimalistic feel and not make the overall thing look too busy.

## Modelling Process
Firstly I created the base shape and blocked out each component to it's rough final size. Then I filleted the edges and made it look neat and tidy. However I hadn't textured the base or the top...

## Problems
When I did decide to do the texturing I encountered multiple problems, especially on the curved face of the cylindrical base. I did multiple sketches and iterations to find the perfect sizing while still making it look nice. Even though I did the texturing last, if you look at my timeline you may see it is not at the end. This is because I used the parametric timeline in fusion so i could move forwards and backwards, this allowed me to do the texturing in a convenient time throughout the modelling process.

## BOM
The project is relatively simple, requiring the 3d printed enclosure, 6802zz bearings and a 12mm metal rod (> 77.5mm). It is within a $30 budget and may be cheaper with discounts and offers. For the parts, I looked towards JLC3DP, which is good because they have a wide range of materials and there is not minimum spend. For the other parts I found good, cheap ones on AliExpress.
